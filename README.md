# COCO Preprocessing for Object Detection

Milestone 1 of the Autonomous Object Detection Project.

### 📁 Contents
- `scripts/filter_and_convert.py` – Filter COCO and convert to YOLO
- `scripts/explore_coco.py` – Data exploration and visualization
- `outputs/exploration/` – Generated charts and sample images
- `data.yaml` – YOLOv8 dataset configuration

### ⚙️ Steps
1. Data filtering and YOLO label conversion  
2. Dataset exploration and visualization  
3. Preprocessed dataset ready for Milestone 2 (model training)
